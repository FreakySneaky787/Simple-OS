Windows programs on Simple OS

Simple OS is not Windows – but many Windows programs and games still run. Here is what to expect.

How it works

  1. Double-click the program (a file ending in .exe or .msi), or right-click it and choose Run with SOS Bridge.
  2. The first time, Simple OS offers to install SOS Bridge. It is the free app Bottles with Wine, from Flathub – about 700 MB to download, once. You can also tick it in the Setup Wizard (Menu → Help → Setup Wizard, page “Extras”) or install it in the Software Center.
  3. The program opens. The very first time, SOS Bridge sets itself up and downloads its Wine version – that takes about a minute. After that a program opens within a few seconds. Programs you install (with their setup file) appear in the menu afterwards, like any other app – Simple OS adds them from the program's start menu shortcuts.

Wine does not need a Windows licence and does not install Windows. A program that does not work can't harm your Simple OS – at worst it does not start.

What usually works

Many older and simple programssmall tools, older office and drawing programs, many classic games
Lots of gamesthrough Steam and its Proton (Gaming Support in the Setup Wizard), or through Heroic and Lutris for Epic, GOG and others
Programs with a Linux versionalways prefer it – look in the Software Center first

What usually doesn't work

Microsoft 365 (Word, Excel …)use LibreOffice or ONLYOFFICE (both open Word and Excel files), or Office in the browser at office.com
Current Adobe apps (Photoshop, Premiere …)GIMP or Krita for pictures, Inkscape for vector graphics, Kdenlive for video
Games with kernel anti-cheate.g. Valorant, and some online shooters – they refuse to start outside Windows. Check protondb.com before you buy a game.
Windows itself, drivers and system toolsWindows installation media and setup tools (e.g. the Media Creation Tool or a Windows setup.exe), Windows updates, drivers, antivirus programs and “PC cleaners” are made for Windows itself – they can't work here, and are not needed.

Steam: play Windows-only games

Steam runs most Windows games with its own Proton. For games Valve has not tested yet, switch it on once:

  1. Open Steam → Steam menu (top left) → Settings → Compatibility.
  2. Turn on “Enable Steam Play for all other titles” and restart Steam.

Simple OS never changes Steam's settings for you.

Simple OS · SOS Bridge is the name of this bundle (Bottles + Wine + the double-click), not a Windows layer of our own. Bottles: usebottles.com
