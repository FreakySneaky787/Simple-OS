Programmes Windows sur Simple OS

Simple OS n’est pas Windows – mais beaucoup de programmes et de jeux Windows fonctionnent quand même. Voici à quoi vous attendre.

Comment ça marche

  1. Double-cliquez sur le programme (un fichier qui se termine par .exe ou .msi), ou faites un clic droit dessus et choisissez Exécuter avec SOS Bridge.
  2. La première fois, Simple OS propose d’installer SOS Bridge. C’est l’application gratuite Bottles avec Wine, depuis Flathub – environ 700 Mo à télécharger, une seule fois. Vous pouvez aussi la cocher dans l’assistant de configuration (Menu → Aide → Assistant de configuration, page « Extras ») ou l’installer depuis le Centre de logiciels.
  3. Le programme s’ouvre. La toute première fois, SOS Bridge se configure et télécharge sa version de Wine – cela prend environ une minute. Ensuite, un programme s’ouvre en quelques secondes. Les programmes que vous installez (avec leur fichier d’installation) apparaissent ensuite dans le menu, comme toute autre application – Simple OS les ajoute à partir des raccourcis du menu Démarrer du programme.

Vos fichiers : dans un programme Windows, Documents, Téléchargements, Images, Musique et Vidéos sont vos propres dossiers de Simple OS – ce que vous y enregistrez se retrouve comme d’habitude dans le gestionnaire de fichiers.

Vous avez téléchargé l’installateur Windows d’une application qui a sa propre version pour Simple OS – Steam, Discord, Spotify, VLC, Zoom et d’autres ? Simple OS vous indique alors cette version dans le Centre de logiciels : elle fonctionne bien mieux que la version Windows.

Wine n’a pas besoin de licence Windows et n’installe pas Windows. Un programme qui ne fonctionne pas ne peut pas endommager votre Simple OS – au pire, il ne démarre pas.

Ce qui fonctionne en général

Beaucoup de programmes anciens et simplespetits outils, anciens programmes de bureautique et de dessin, beaucoup de jeux classiques
De nombreux jeuxvia Steam et son Proton (Support des jeux dans l’assistant de configuration), ou via Heroic et Lutris pour Epic, GOG et d’autres
Les programmes qui ont une version Linuxpréférez-la toujours – regardez d’abord dans le Centre de logiciels

Ce qui ne fonctionne généralement pas

Microsoft 365 (Word, Excel …)utilisez LibreOffice ou ONLYOFFICE (les deux ouvrent les fichiers Word et Excel), ou Office dans le navigateur sur office.com
Les applications Adobe actuelles (Photoshop, Premiere …)GIMP ou Krita pour les images, Inkscape pour le graphisme vectoriel, Kdenlive pour la vidéo
Les jeux avec anti-triche au niveau du noyaup. ex. Valorant et certains jeux de tir en ligne – ils refusent de démarrer hors de Windows. Consultez protondb.com avant d’acheter un jeu.
Windows lui-même, les pilotes et les outils systèmeLes supports et outils d’installation de Windows (p. ex. l’outil Media Creation Tool ou un setup.exe de Windows), les mises à jour de Windows, les pilotes, les antivirus et les « nettoyeurs de PC » sont faits pour Windows lui-même – ils ne peuvent pas fonctionner ici, et ne sont pas nécessaires.

Steam : jouer aux jeux uniquement Windows

Steam exécute la plupart des jeux Windows avec son propre Proton. Pour les jeux que Valve n’a pas encore testés, activez-le une fois :

  1. Ouvrez Steam → menu Steam (en haut à gauche) → Paramètres → Compatibilité.
  2. Activez « Activer Steam Play pour tous les autres titres » et redémarrez Steam.

Simple OS ne modifie jamais les paramètres de Steam à votre place.

Simple OS · SOS Bridge est le nom de cet ensemble (Bottles + Wine + le double-clic), pas une couche Windows maison. Bottles : usebottles.com
