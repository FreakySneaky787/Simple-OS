Simple OS

Keep it Simple. Debian 12 with Openbox – here's what you need to get going.

Quick start

  1. Connect to Wi-Fi. Click the network icon or the IP address in the taskbar, pick your network and enter the password. From a terminal: simpleos-wifi. Cable connections work on their own. The Setup Wizard also helps you with this on your first login.
    VPN, fixed IP and other extras: right-click the network icon in the system tray and choose Edit Connections.
  2. Install your software. Run simpleos-setup to pick a browser, an office suite, gaming tools and dark or light mode. It also opens once after your first login.
  3. That's it. Updates take care of themselves: when some are ready, a message appears – click it to install. You can also check any time under Settings → Software Updates.

System tools

Taskbar designer

Right-click the desktop and go to Settings → Taskbar & Panel, or run simpleos-taskbar-select. You can change position, size, style and whether the clock and network display are shown.

Openbox settings

Run obconf for window theme, fonts and desktop count. Shortcuts and window rules live in ~/.config/openbox/rc.xml. After editing that file, apply it with openbox --reconfigure.

Network info

Super+N shows your LAN IP, gateway, hostname, VPN status and public IP. For the same output in a terminal, run simpleos-netinfo --text.

To open this page again, right-click the desktop and choose Help → Welcome to Simple OS.
