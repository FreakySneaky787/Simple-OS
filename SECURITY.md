# Security Policy

## Supported versions

Only the **latest release** of Simple OS gets security fixes:
https://github.com/FreakySneaky787/Simple-OS/releases/latest

Preview and beta versions of Simple OS 2.0 "Rigi" (branch `trixie`) are for testing and get no security support.
Once 2.0 is released, the last 1.x release keeps getting fixes for a while, so there is time to upgrade (how long
will be announced with 2.0).

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report them privately instead: go to the **Security** tab of this repository and click
**Report a vulnerability**. Please describe what is affected, how to reproduce it and which version you use.

You will get an answer as soon as possible. Once a fix is released, the report can be made public, with credit to
you if you like.
