# Simple OS – codename ideas

Nothing here is decided yet. A name goes into [ROADMAP.md](../ROADMAP.md) and the milestone only once it is chosen.

- **One codename per big release** (2.0, 3.0 …), not for every 2.x.
- **Theme: Swiss mountains** – calm, solid, clear, like Simple OS.
- **No ä, ö, ü** – easy to type everywhere (URLs, package names, announcements).

## Favourites

| Version | Codename | Say it (English) | Why |
|---|---|---|---|
| 2.0 | **Rigi** | "REE-gee" | short, friendly, the "Queen of the Mountains" |
| 3.0 | **Pilatus** | "pi-LAH-tus" | striking, next to Lucerne |
| 4.0 | **Eiger** | "EYE-ger" | known all over the world |

You can see Rigi, Pilatus and Eiger from Lake Lucerne – a nice small series.

## More mountains (no umlauts)

| Name | Say it | Note |
|---|---|---|
| Niesen | "NEE-zen" | the pyramid above Lake Thun |
| Stanserhorn | "SHTAN-zer-horn" | long, but clear |
| Brienzer Rothorn | – | too long, better as a wallpaper motif |
| Moleson | "mo-leh-ZON" | western Switzerland (really Moléson – written without the accent) |
| Monte Generoso | – | Ticino, sounds nice, but long |
| Piz Bernina | "pits ber-NEE-na" | highest mountain of the Eastern Alps |
| Napf | "nahpf" | hard to say |
| Titlis | "TIT-lis" | careful: invites jokes in English |
| Matterhorn | – | heavily used as a brand, better avoid |

## Other themes

- **Swiss lakes:** Lugano, Thun, Brienz, Sils, Lauerz
- **Calm nature words (English):** Meadow, Harbor, Stillwater, Driftwood, Lantern

## Before choosing

- Check that no well-known software already uses the name.
- A default wallpaper for the release (e.g. 2.0 "Rigi" as a stylised mountain in the Simple OS colours) makes the name
  visible.
